Agent Architecture

Orchestrator / SupervisorChooses next stage, handles approvals, exceptions and closure.
Intake & Context AgentCreates Case ID, validates input and initializes memory.
Customer Intelligence AgentSentiment, issue detection and confidence analysis.
Triage & Routing AgentSeverity, department ownership and escalation decisions.
Resolution / Action AgentRecommended action, re-planning and ticket creation.

Tools / Data Sources

  • SQLite case database
  • Routing & severity rule base
  • Human approval controls
  • Simulated ticket tool
  • Audit log and dashboard

Autonomy Levels

  • Fully autonomous: case creation, logging
  • Act then report: NLP analysis, low-risk routing
  • Suggest: ambiguous classification
  • Approve: high/critical actions

Responsible AI & Limitations

  • No live Flipkart internal integration.
  • No confidential customer data required.
  • No automated refunds, penalties, pricing changes or external messages.
  • High-risk and ambiguous cases require human oversight.
  • Rule-based NLP may struggle with slang, multilingual reviews and subtle sarcasm.
  • Free hosting persistence may reset after restart/redeploy.
